Modelado y Programación
====================

Ejercicios de Laboratorio I
------------------

### Fecha de entrega: 17 de Marzo de 2025

Uso: Compilar al hacer:

```
$ mvn compile
```

Pasa todas sus pruebas unitarias al hacer:

```
$ mvn test
```

Por último, ejecutar correctamente el programa de la clase
[`Ejecutable`] al ejecutar:

```
$ mvn install
...
$ java -jar target/ejercicio1.jar
```
